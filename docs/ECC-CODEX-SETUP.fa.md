# راهنمای راه‌اندازی ECC برای Codex — مخزن miladVR/codex

این راهنما برای نصب رسمی **Everything Claude Code (ECC)** در محیطی است که Codex App یا Codex CLI واقعاً در آن اجرا می‌شود. افزودن این فایل‌ها به GitHub یا ایجاد Pull Request، **به معنی نصب افزونه روی حساب یا رایانه شما نیست**.

## چه چیزی در مخزن تنظیم شده؟
- فایل `AGENTS.md` در ریشه مخزن، روند استاندارد برنامه‌ریزی، تست، پیاده‌سازی، بازبینی و تأیید را به Codex معرفی می‌کند.
- دو اسکریپت کمکی برای Windows PowerShell و محیط‌های Linux/macOS/Codespaces، دستورهای **رسمی نصب بومی ECC در Codex** را اجرا می‌کنند.
- کد اجرایی Cloze Studio و سامانه امتیازدهی آتش‌نشانی تغییر نکرده است.

## نصب رسمی در Codex CLI
پیش‌نیاز: نسخه‌ای از Codex CLI که فرمان‌های `codex plugin` را پشتیبانی کند، دسترسی به GitHub و مجوز نصب افزونه.

بعد از بررسی منبع رسمی `https://github.com/affaan-m/ECC`، در ترمینال **همان محیطی که Codex در آن اجرا می‌شود** وارد کنید:

```bash
codex plugin marketplace add affaan-m/ECC
codex plugin add ecc@ecc
codex plugin list --json
```

دو فرمان اول در نسخه‌های پشتیبانی‌شده به‌صورت idempotent طراحی شده‌اند؛ فرمان سوم برای بررسی فهرست افزونه‌هاست. به دنبال `ecc@ecc` در وضعیت فعال باشید. اگر نصب یا بررسی خطا داد، نصب را موفق فرض نکنید. پس از نصب، Codex را مجدداً راه‌اندازی کنید. در صورت نمایش درخواست مجوز/اعتماد برای hooks، پیش از تأیید آن‌ها را بررسی کنید.

### روش یک‌مرحله‌ای با اسکریپت این مخزن

**Windows PowerShell** (داخل ریشه مخزن):
```powershell
.\scripts\setup-ecc-codex.ps1 -CheckOnly
.\scripts\setup-ecc-codex.ps1
```

**Linux / macOS / GitHub Codespaces** (داخل ریشه مخزن):
```bash
bash scripts/setup-ecc-codex.sh --check
bash scripts/setup-ecc-codex.sh
```

اسکریپت‌ها قبل از نصب، در ترمینال تأیید صریح `INSTALL` می‌خواهند؛ رمز یا توکن را دریافت یا ذخیره نمی‌کنند. این فایل‌ها **از GitHub Actions اجرا نمی‌شوند**؛ باید در محیط Codex موردنظر اجرا شوند.

## بررسی پس از نصب
1. دستور `codex plugin list --json` را اجرا و وجود `ecc@ecc` را تأیید کنید.
2. یک نشست تازه Codex در ریشه همین مخزن باز کنید.
3. از Codex بخواهید فایل `AGENTS.md` را خوانده، یک تغییر کوچک برنامه‌ریزی کند و دستور تست مناسب پروژه را پیشنهاد دهد.
4. اگر ECC بارگذاری شده باشد، می‌توان در Codex از مهارت `$configure-ecc` برای بازبینی پیکربندی استفاده کرد.
5. از Codex بخواهید نام مهارت‌های واقعاً دردسترس را گزارش دهد؛ وجود راهنما به‌تنهایی اثبات نصب ۳۱۴ مهارت نیست.

### به‌روزرسانی رسمی
```bash
codex plugin marketplace upgrade ecc
codex plugin add ecc@ecc
codex plugin list --json
```

از روش قدیمی `scripts/sync-ecc-to-codex.sh` **هم‌زمان** با افزونه بومی استفاده نکنید. مطابق راهنمای ECC، لایه‌گذاری این روش‌ها می‌تواند به تنظیمات تکراری منجر شود.

## نکات امنیتی
- فقط منبع رسمی `affaan-m/ECC` را نصب کنید و وابستگی‌های احتمالی و سطح دسترسی hookها و MCPها را بررسی کنید.
- روی رایانه سازمانی یا مخازن محرمانه، تأیید امنیت اطلاعات و مجوزهای سازمانی لازم است.
- نصب افزونه روی یک سیستم، آن را به تمام نشست‌ها یا ابزارهای دیگر منتقل نمی‌کند؛ Codex از وضعیت نصب مربوط به `CODEX_HOME` فعال استفاده می‌کند.
- این تنظیمات هیچ دسترسی جدیدی به ChatGPT در گفت‌وگوهای عادی نمی‌دهد.
- تغییرات اصلی پروژه‌ها باید جداگانه تست و پیش از ادغام بازبینی شوند.
