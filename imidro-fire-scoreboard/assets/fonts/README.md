# B Zar embedded fonts

Persian/Arabic and Latin webfont subsets generated from the existing B Zar Regular and Bold fonts supplied by the project owner's Windows installation. Original font names and metadata are retained. The source fonts permit embedding in their OS/2 metadata (fsType=0). These font assets are not covered by the application's MIT license; their original rights remain with their respective owners. Original TTF files are not stored in this repository.
