# سامانه آفلاین امتیازدهی مسابقات آتش‌نشانان ایمیدرو

نرم‌افزار دسکتاپ ویندوز برای ثبت، کنترل، تأیید و نمایش زنده نتایج سومین دوره مسابقات علمی و عملیاتی آتش‌نشانان ایمیدرو. تمام اطلاعات روی همان رایانه ذخیره می‌شود و اجرای مسابقه به اینترنت وابسته نیست.

## قابلیت‌ها

- پنل مدیریت فارسی و راست‌چین
- ثبت زمان با سه فهرست انتخابی مجزای دقیقه، ثانیه و صدم ثانیه؛ مقدار پیش‌فرض خالی است تا صفر اشتباهی ثبت نشود
- صف تأیید سرداور و قفل نتیجه پیش از انتشار عمومی
- رتبه‌بندی خودکار پنج رشته و جدول مجموع رتبه‌ها
- پنجره مستقل و تمام‌صفحه برای مانیتور یا ویدئوپروژکتور دوم
- اعلان دیداری و صدای کوتاه هنگام تأیید نتیجه جدید
- ذخیره آفلاین، ثبت سوابق تغییرات و حداکثر ۲۵ پشتیبان خودکار
- خروجی نصب‌شونده و نسخه پرتابل ویندوز

## نصب روی ویندوز با یک فرمان

پس از انتشار نسخه رسمی، PowerShell را باز کنید و این فرمان را اجرا کنید:

```powershell
powershell -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/miladVR/codex/main/imidro-fire-scoreboard/scripts/install.ps1 | iex"
```

اسکریپت، جدیدترین Release دارای برچسب `imidro-fire-v*` را پیدا می‌کند، فایل Setup را بارگیری می‌کند و نصب‌کننده را اجرا می‌کند. پس از نصب، اینترنت برای کار با سامانه لازم نیست.

## اجرای مسابقه

1. برنامه را باز و در بخش «تیم‌ها» تیم‌های حاضر را تعریف کنید.
2. از «ثبت نتیجه»، تیم و رشته را انتخاب و همه اجزای زمان را از فهرست‌ها تعیین کنید.
3. نتیجه در صف «تأیید سرداور» قرار می‌گیرد و تا پیش از تأیید روی نمایشگر عمومی اثر ندارد.
4. مانیتور دوم را در ویندوز روی حالت Extend بگذارید و «بازکردن نمایشگر» را انتخاب کنید.
5. از بخش تنظیمات، عنوان، محل برگزاری، پیام نمایشگر و صدای اعلان را کنترل کنید.

داده‌های اجرایی در پوشه داده کاربر ویندوز نگه‌داری می‌شوند. دکمه «نسخه پشتیبان» یک فایل JSON قابل انتقال تحویل می‌دهد.

## توسعه محلی

نیازمندی: Node.js 22 یا جدیدتر.

```powershell
git clone https://github.com/miladVR/codex.git
cd codex\imidro-fire-scoreboard
npm install
npm test
npm start
```

ساخت فایل‌های ویندوز:

```powershell
npm run dist:win
```

خروجی در پوشه `release` ساخته می‌شود.

## انتشار نسخه رسمی

Workflow گیت‌هاب با هر برچسب منطبق با `imidro-fire-v*` تست‌ها را اجرا، نسخه Setup و Portable ویندوز را ایجاد و به Release همان برچسب پیوست می‌کند:

```bash
git tag imidro-fire-v1.0.0
git push origin imidro-fire-v1.0.0
```

پیش از روز مسابقه، نصب، بازشدن نمایشگر دوم، سیستم صوتی، نسخه پشتیبان و قوانین نهایی محاسبه رتبه باید در یک تمرین کامل آزمایش شوند.
