# سامانه آفلاین امتیازدهی مسابقات آتش‌نشانان ایمیدرو

نرم‌افزار دسکتاپ ویندوز برای ثبت، کنترل، تأیید و نمایش زنده نتایج سومین دوره مسابقات علمی و عملیاتی آتش‌نشانان ایمیدرو. تمام اطلاعات روی همان رایانه ذخیره می‌شود و اجرای مسابقه به اینترنت وابسته نیست.

## نسخه ۱.۳.۱ — پاک‌سازی کامل پس از تمرین

دکمه قرمز «پاک‌کردن همه داده‌ها و شروع از صفر» در پایین منوی سمت راست، با دو پرسش مستقل، خلاصه داده‌ها، انتظار دوثانیه‌ای و تایپ «تایید»، همه داده‌های مسابقه و پشتیبان‌های خودکار داخلی را حذف می‌کند و تنظیمات اولیه را برمی‌گرداند. پنل و نمایشگر سالن فوراً خالی می‌شوند؛ داده‌ها پس از بازکردن مجدد نیز خالی می‌مانند و شماره تیم‌ها از T01 شروع می‌شود. فایل‌های PDF و پشتیبان‌های دستی بیرون از برنامه حذف نمی‌شوند. نصب و ارتقا به‌تنهایی داده‌ها را پاک نمی‌کند.

## امکانات عملیات ترکیبی

- ثبت مستقل هر ورزشکار با زمان و جریمه فردی؛ Pending / Partial / Completed.
- شماره‌های ۱ تا ۲۲ و ۲۳ تا ۴۴ برای ۲۲ تیم، لاین مخالف خودکار در دور دوم و گروه‌های اجرای ثابت.
- رده‌بندی زنده انفرادی و تیمی؛ میانگین دو زمان نهایی پس از تکمیل هر دو رکورد.
- حذف دومرحله‌ای با خلاصه داده، انتظار دوثانیه‌ای، تایپ «تایید» و کنترل درخواست قدیمی در backend.
- تنظیم عنوان، تاریخ، محل، زیرنویس، لوگوی مسابقه و سه حامی؛ تصاویر آفلاین PNG/JPEG/WebP.
- ارتقای داده به نسخه ۴ با حفظ نتایج قبلی؛ جریمه مشترک قدیمی جدا نگه داشته می‌شود.
- [معماری، مدل‌ها و آزمون‌های پذیرش](docs/ARCHITECTURE-FA.md) و [Schema داده](docs/staged-data.schema.json).

## نسخه ۱.۲ — نوبت دستی و تابلو زنده هر رشته

نوبت دستی/خودکار ماندگار و مستقل از رتبه، تابلو جداگانه برای پنج رشته، انتشار فوری نتایج با برچسب موقت، کنترل انتخاب نمایشگر و بازیابی IPC اضافه شده است. PDF رسمی همچنان فقط نتایج تأییدشده را محاسبه می‌کند. پس از شروع ثبت نتایج، قرعهٔ محدودهٔ شروع‌شده قفل می‌شود. این امکانات در نسخه ۱.۳.۱ نیز حفظ شده‌اند.

[تحلیل خطا، قرارداد API، schema و چک‌لیست تست](docs/LIVE-DISPLAY-VERIFICATION-FA.md). برای بررسی رابط واقعی: `npm run test:smoke`؛ برای اجرای نسخهٔ محلی: `npm start`. Mirror در رابط، پیش‌نمایش پنجرهٔ عمومی است؛ حالت Extend ویندوز را با Win+P تنظیم کنید.

## نسخه ۱.۱

- فونت B Zar تعبیه‌شده و لوگوی رسمی ارسالی مسابقه
- قرعه‌کشی عمومی و مستقل هر رشته، ثبت دائمی نوبت‌ها و تأیید اجرای مجدد
- نمایش قرعه‌کشی در سالن و گزارش PDF همه نوبت‌ها
- گزارش PDF نتایج با نام کامل امور آموزش و توسعه شایستگی مجتمع مس سرچشمه رفسنجان
- صدای ملودیک آفلاین، کنترل بلندی و آزمایش صدا
- نمایش همه تیم‌ها با صفحه‌بندی، کنترل گردش و رعایت کاهش حرکت
- حفظ داده‌های نسخه ۱.۰ هنگام ارتقا

فرمان نصب همیشه آخرین Release منتشرشده با برچسب `imidro-fire-v*` را نصب می‌کند؛ از نسخهٔ ۱.۲.۰، همین فرمان نوبت دستی قرعه، تابلوهای زندهٔ هر رشته و انتشار فوری نتایج را نصب می‌کند.

## قابلیت‌ها

- پنل مدیریت فارسی و راست‌چین
- ثبت زمان با سه فهرست انتخابی مجزای دقیقه، ثانیه و صدم ثانیه؛ مقدار پیش‌فرض خالی است تا صفر اشتباهی ثبت نشود
- صف تأیید سرداور؛ نتیجه پیش از تأیید با برچسب «موقت» روی تابلو منتشر می‌شود و تأیید آن را رسمی و قفل می‌کند
- رتبه‌بندی خودکار پنج رشته و جدول مجموع رتبه‌ها
- پنجره مستقل و تمام‌صفحه برای مانیتور یا ویدئوپروژکتور دوم
- اعلان دیداری و صدای کوتاه هنگام تأیید نتیجه جدید
- ذخیره آفلاین، ثبت سوابق تغییرات و حداکثر ۲۵ پشتیبان خودکار
- خروجی نصب‌شونده و نسخه پرتابل ویندوز

## نصب روی ویندوز با یک فرمان

در PowerShell این فرمان را اجرا کنید؛ همیشه آخرین Release رسمی را نصب می‌کند:

```powershell
irm "https://raw.githubusercontent.com/miladVR/codex/main/imidro-fire-scoreboard/scripts/install.ps1" | iex
```

فرمان بالا را کامل و در یک خط کپی کنید؛ وسط آدرس Enter نزنید. شکستن آدرس، از جمله بین mi و ladVR، می‌تواند خطای 404 و «دستور شناخته نشد» ایجاد کند. فقط متن داخل کادر را در PowerShell وارد کنید. این فرمان آخرین Release رسمی با برچسب imidro-fire-v را نصب می‌کند.

اسکریپت، جدیدترین Release دارای برچسب `imidro-fire-v*` را پیدا می‌کند، فایل Setup را بارگیری می‌کند و نصب‌کننده را اجرا می‌کند. پس از نصب، اینترنت برای کار با سامانه لازم نیست.

## اجرای مسابقه

1. برنامه را باز و در بخش «تیم‌ها» تیم‌های حاضر را تعریف کنید.
2. از «ثبت نتیجه»، تیم و رشته را انتخاب و همه اجزای زمان را از فهرست‌ها تعیین کنید.
3. نتیجه فوراً با برچسب «موقت» روی تابلو زنده منتشر می‌شود و هم‌زمان در صف «تأیید سرداور» قرار می‌گیرد؛ پس از تأیید رسمی و قفل می‌شود.
4. مانیتور دوم را در ویندوز روی حالت Extend بگذارید و «بازکردن نمایشگر» را انتخاب کنید.
5. از بخش تنظیمات، عنوان، محل برگزاری، پیام نمایشگر و صدای اعلان را کنترل کنید.

داده‌های اجرایی در پوشه داده کاربر ویندوز نگه‌داری می‌شوند. دکمه «نسخه پشتیبان» یک فایل JSON قابل انتقال تحویل می‌دهد.

فرمان نصب از فهرست عمومی نسخه‌های منتشرشده در `scripts/releases.json` استفاده می‌کند و به GitHub REST API وابسته نیست؛ خطای محدودیت آی‌پی API مانع نصب نمی‌شود. اندازه و SHA-256 فایل Setup پیش از اجرا کنترل می‌شوند. این فهرست پس از انتشار نسخه‌های بعدی توسط workflow نصب به‌روز می‌شود.

## نصب مشخص نسخه ۱.۳.۱

```powershell
& ([scriptblock]::Create((irm "https://raw.githubusercontent.com/miladVR/codex/main/imidro-fire-scoreboard/scripts/install.ps1"))) -Version "1.3.1"
```

برای نصب مشخص، وجود Release همان نسخه و Setup آن بررسی می‌شود؛ به نسخه قدیمی عقب‌گرد نمی‌کند. پیش از ارتقا از داده‌ها پشتیبان بگیرید.

## توسعه محلی

نیازمندی: Node.js 22 یا جدیدتر.

```powershell
git clone https://github.com/miladVR/codex.git
cd codex\imidro-fire-scoreboard
npm install
npm test
npm start
```

ساخت فایل‌های ویندوز:

```powershell
npm run dist:win
```

خروجی در پوشه `release` ساخته می‌شود.

## انتشار نسخه رسمی

Workflow گیت‌هاب با هر برچسب منطبق با `imidro-fire-v*` تست‌ها را اجرا، نسخه Setup و Portable ویندوز را ایجاد و به Release همان برچسب پیوست می‌کند:

```bash
git tag imidro-fire-v1.3.1
git push origin imidro-fire-v1.3.1
```

پیش از روز مسابقه، نصب، بازشدن نمایشگر دوم، سیستم صوتی، نسخه پشتیبان و قوانین نهایی محاسبه رتبه باید در یک تمرین کامل آزمایش شوند.
