# نسخه ۱.۶.۰ — تم سفید و کرم و تنظیمات کامل ظاهر

- زمینه اصلی سفید، فرم‌ها و جدول‌ها کرم، متن و نوشته دکمه‌ها مشکی. همه پنل‌ها، نمایشگر، راهنما و پنجره‌های تأیید از یک پالت مشترک استفاده می‌کنند.
- انتخاب B Zar همراه برنامه، Tahoma، Arial یا نام دقیق فونت نصب‌شده روی ویندوز. اندازه پنل ۱۶ تا ۲۴، سقف متن سالن ۱۸ تا ۴۴ پیکسل، ضخامت معمولی/پررنگ و انتخاب فونت اعداد و زمان‌ها.
- تنظیم مستقل رنگ متن اصلی، متن فرعی، متن تأکیدی، کادرها، ورودی‌ها و حاشیه‌ها.
- تنظیم رنگ نوشته دکمه‌ها، زمینه دکمه معمول، تأیید، حذف و فرعی؛ اندازه جمع‌وجور یا مناسب لمس.
- زمینه تک‌رنگ یا گرادینت، پنج تم آماده، پیش‌نمایش کامل و پیام خوانایی کم. انتخاب‌های دلخواه حتی با کنتراست کم قابل ذخیره‌اند.
- «ذخیره ظاهر» مستقل از مشخصات مسابقه و «بازگشت به ظاهر سفید و کرم» بدون حذف نتایج.
- حفظ تنظیمات در پشتیبان و بازیابی؛ نسخه‌های قدیمی ظاهر را به پیش‌فرض جدید منتقل می‌کنند و محتوای مسابقه را حفظ می‌کنند.
- فونت سالن با فضای ردیف‌ها و ستون زمان تطبیق می‌یابد تا همه نتایج و رقم‌ها کامل دیده شوند.
- به‌روزرسانی راهنمای آفلاین، PDF، اسکیما و فرمان نصب.

قالب داده همچنان نسخه ۶ است؛ تنظیمات ظاهر با appearanceVersion برابر ۲ ذخیره می‌شوند. گزارش PDF از قالب ثابت مناسب چاپ استفاده می‌کند.
