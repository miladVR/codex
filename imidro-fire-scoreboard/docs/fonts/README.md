# فونت راهنمای PDF

فایل PDF نهایی دارای نسخه تعبیه‌شده و زیرمجموعه‌شده فونت B Zar است و برای مشاهده آن نیازی به نصب فونت وجود ندارد.

برای بازسازی PDF، نسخه قانونی فونت `BZar.ttf` را در همین پوشه قرار دهید و سپس `docs/build_user_guide.py` را اجرا کنید. فایل اصلی فونت به دلیل رعایت حقوق انتشار در مخزن نگهداری نمی‌شود.
