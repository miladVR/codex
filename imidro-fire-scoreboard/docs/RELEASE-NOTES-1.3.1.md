# نسخه ۱.۳.۱ — پاک‌سازی کامل پس از تمرین

- دکمه قرمز «پاک‌کردن همه داده‌ها و شروع از صفر» در پایین منوی سمت راست.
- دو مرحله تأیید، خلاصه داده‌ها، انتظار دوثانیه‌ای و تایپ «تایید»؛ کنترل در لایه اصلی برنامه و فقط برای پنل مدیریت.
- حذف همه تیم‌ها، ورزشکاران، رکوردها، جریمه‌ها، قرعه‌ها، سوابق، لوگوهای سفارشی و پشتیبان‌های خودکار داخلی؛ بازگشت تنظیمات به حالت اولیه.
- خالی‌شدن فوری پنل و تابلو سالن، حفظ حالت خالی پس از بازکردن مجدد و شروع شماره تیم جدید از T01.
- راهنمای فارسی و PDF به‌روز و نصب بدون وابستگی به GitHub REST API با کنترل اندازه و SHA-256.

نصب نسخه جدید داده‌های موجود را حفظ می‌کند. پاک‌سازی کامل فقط پس از تأیید دکمه قرمز انجام می‌شود. فایل‌های PDF و پشتیبان‌های دستی خارج از برنامه حذف نمی‌شوند.
