# IMIDRO Fire Scoreboard 1.5.0

- آزمون علمی با پنج شرکت‌کننده مستقل: نام و نمره جداگانه، ثبت مرحله‌ای، جمع پنج نمره و رتبه زنده پس از تکمیل؛ حفظ امتیاز قدیمی بدون ریزنمرات ساختگی.
- عکس مستقل ورزشکاران در تمام رشته‌ها؛ تصویر پیش‌فرض مرد؛ عکس‌های فشرده داخل پشتیبان و گزارش تیم.
- منوی بازیابی پشتیبان JSON با اعتبارسنجی، کپی اطلاعات فعلی و تأیید دومرحله‌ای؛ بازیابی کامل پس از صفرکردن برنامه.
- منوی گزارش‌گیری: کلی زنده و رسمی، هر رشته، انفرادی ترکیبی، ریز نتایج تیم و قرعه‌کشی.
- انتخاب تک‌صفحه‌ای یا چندصفحه‌ای، توضیحات اختیاری زیر جدول و چهار محل امضا در همه گزارش‌های PDF.
- تغییر ستون «تکمیل» به «مراحل انجام‌شده»؛ راهنماهای زمینه‌ای و راهنمای فارسی متنی و PDF به‌روز.
- مدل داده نسخه ۶ و مهاجرت بدون حذف داده از نسخه‌های قبلی؛ Setup و Portable ویندوز ۶۴ بیتی.

## نصب مشخص نسخه

```powershell
& ([scriptblock]::Create((irm "https://raw.githubusercontent.com/miladVR/codex/main/imidro-fire-scoreboard/scripts/install.ps1"))) -Version "1.5.0"
```

پیش از ارتقا پشتیبان بگیرید. نتیجه علمی قدیمی حفظ می‌شود؛ اولین ثبت نمره مستقل آن را با نتیجه جدید پنج‌نفره جایگزین می‌کند. فایل Setup با اندازه و SHA-256 ثبت‌شده در manifest بررسی می‌شود؛ دریافت از GitHub API لازم نیست.
