# نسخه ۱.۴.۰ — راهنمای داخل نرم‌افزار

- آیکون کوچک «؟» کنار بخش‌ها، فیلدها، ستون‌های جدول و دکمه‌های عملیاتی؛ توضیح همان قسمت با کلیک.
- راهنمای مستقل کنار دکمه‌های غیرفعال؛ توضیح علت غیرفعال‌بودن قرعه‌کشی، قفل نتیجه و ناقص‌بودن ترکیبی.
- گزینه «راهنمای نرم‌افزار» در منوی سمت راست با متن کامل فارسی، فهرست بخش‌ها و جست‌وجو؛ کاملاً آفلاین.
- حفظ مقادیر فرم هنگام مطالعه راهنمای کوتاه و حفظ جست‌وجو هنگام دریافت نتیجه زنده.
- راهنمای نمایشگر سالن بدون دسترسی تغییر داده؛ کلیک راهنما هیچ عملیات ثبت یا حذف را اجرا نمی‌کند.
- راهنمای Markdown و PDF و دستور نصب به‌روز شده‌اند. داده‌های نسخه‌های قبل هنگام ارتقا حفظ می‌شوند.
