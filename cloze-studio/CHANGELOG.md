# Changelog

## 1.1.0 — 2026-09-10

- Redesigned the editor with question-type cards, separate branding and page settings, and a responsive worksheet preview.
- Added a local PNG/JPEG/WebP logo picker with replacement, removal and validation.
- Added institution or teacher names to worksheet and answer-key headers.
- Added A4, A5, Letter and Legal sizes, with portrait and landscape printing.
- Added multiple-choice, true/false, matching and short-answer question editors alongside gap-fill.
- Added mixed worksheets with continuous numbering, stable matching options and a combined answer key.
- Added section inclusion controls, original bilingual examples, incomplete-question warnings and print validation.
- Expanded regression coverage to sixteen tests. Cross-browser visual and physical printing checks remain outstanding.

## 1.0.0 — 2026-09-09

- Released the English/Persian gap-fill worksheet builder with word-bank and answer-key printing.
- Added Unicode-aware word selection, RTL handling, keyboard controls and seven engine regression tests.
