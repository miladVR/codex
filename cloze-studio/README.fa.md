# Cloze Studio — سازنده تمرین زبان

[English](README.md)

این ابزار متن درس را به تمرین جای‌خالی تبدیل می‌کند. مدرس کلمات را انتخاب می‌کند و برنامه برگه تمرین، بانک کلمات و پاسخ‌نامه جداگانه می‌سازد.

## استفاده بدون برنامه‌نویسی

۱. فایل ZIP پروژه را دریافت و از حالت فشرده خارج کنید.

۲. فایل `index.html` را از پوشه `dist` با مرورگر باز کنید.

۳. متن دلخواه را وارد کنید. روی هر کلمه‌ای که باید جای‌خالی شود کلیک کنید؛ با کلیک دوباره، کلمه برمی‌گردد.

۴. عنوان و زبان برگه را تنظیم کنید. در صورت نیاز بانک کلمات و پاسخ‌نامه را فعال کنید.

۵. «پیش‌نمایش چاپ» و سپس «چاپ / ذخیره PDF» را بزنید. برای دریافت فایل، در پنجره چاپ گزینه «Save as PDF» را انتخاب کنید. سربرگ و پابرگ خود مرورگر را خاموش کنید تا آدرس صفحه روی برگه چاپ نشود.

## قابلیت‌ها

- رابط فارسی و انگلیسی، همراه با تنظیم مستقل زبان برگه تمرین.
- پشتیبانی از متن فارسی، انگلیسی، نیم‌فاصله و بندهای متن.
- انتخاب مستقل هر بار تکرار یک کلمه؛ انتخاب یک کلمه، تکرارهای دیگر آن را حذف نمی‌کند.
- شماره‌گذاری پاسخ‌ها بر اساس ترتیب متن.
- بانک کلمات به ترتیب الفبایی؛ کلمات تکراری به تعداد پاسخ‌ها نمایش داده می‌شوند.
- پاسخ‌نامه جداگانه که پس از برگه زبان‌آموز چاپ می‌شود.
- اجرای فایل محلی بدون اینترنت، نصب برنامه، ثبت‌نام یا پرداخت هزینه هوش مصنوعی.

تغییر زبان برگه فقط برچسب‌ها و جهت برگه را عوض می‌کند و متن را ترجمه نمی‌کند. برای دیدن نمونه فارسی، زبان برگه را فارسی کنید و «متن نمونه» را بزنید.

## چند نکته برای استفاده

با تغییر متن، انتخاب کلمات پاک می‌شود. سقف متن ۱۲٬۰۰۰ نویسه است. با بستن یا تازه‌سازی صفحه، کار فعلی پاک می‌شود؛ در پایان PDF بگیرید. برنامه متن درس را به سرور نمی‌فرستد. در نسخه آنلاین، میزبان ممکن است گزارش عادی بازدید صفحه را نگه دارد.

منطق ساخت تمرین و ساختار جاوااسکریپت به‌صورت خودکار بررسی شده‌اند. بررسی ظاهری و چاپ در مرورگرهای مختلف هنوز انجام نشده است. صفحه‌بندی PDF به تنظیمات مرورگر و چاپگر بستگی دارد.

## توسعه و همکاری

کدها با HTML، CSS و JavaScript نوشته شده‌اند و وابستگی نرم‌افزاری ندارند. برای اجرای آزمون‌های توسعه، Node.js نسخه ۲۰ یا بالاتر لازم است:

```sh
npm test
npm run check
```

اگر ابزار مفید بود، می‌توانید به مخزن استار بدهید یا پیشنهاد و اشکال را در بخش Issues ثبت کنید. برای گزارش اشکال از متن نمونه ساختگی استفاده کنید. مجوز کدهای این پروژه [MIT](LICENSE) است.
